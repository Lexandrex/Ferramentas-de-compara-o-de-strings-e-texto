# Comparador de Algoritmos de Busca em Strings

Projeto de demonstração para a disciplina.

## Estrutura
- `index.html` - UI e navegação entre telas.
- `style.css` - estilos.
- `script.js` - lógica de UI e controle de execução.
- `algorithms.js` - implementações de Naive, Rabin-Karp, KMP e Boyer-Moore.
